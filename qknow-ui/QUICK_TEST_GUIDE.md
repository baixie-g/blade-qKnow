# 快速测试指南

## 🚀 快速开始

### 1. 启动Text2Cypher API服务
确保Text2Cypher API服务正在运行：
```bash
# 检查服务状态
curl http://localhost:8003/api/v1/health
```

### 2. 启动前端服务

#### Linux/Mac用户：
```bash
cd qknow-ui
./start-chat-test.sh
```

#### Windows用户：
```cmd
cd qknow-ui
start-chat-test.bat
```

#### 手动启动：
```bash
cd qknow-ui
npm install
npm run dev
```

### 3. 访问测试页面
- 前端服务：http://localhost:5173
- 图谱探索页面：http://localhost:5173/app/graphExploration
- API测试页面：http://localhost:5173/test-chat.html

## 🧪 功能测试

### 测试1：基础连接测试
1. 打开 http://localhost:5173/test-chat.html
2. 点击"检查服务健康状态"
3. 确认返回 `{"status": "healthy"}`

### 测试2：问答功能测试
1. 打开图谱探索页面
2. 点击"智能问答"按钮
3. 输入问题："查询所有人员信息"
4. 查看生成的Cypher查询和结果

### 测试3：设置功能测试
1. 在聊天面板中点击设置按钮
2. 检查可用的LLM模型、数据库、工作流
3. 修改配置并保存

## 🔧 故障排除

### 问题1：API连接失败
**症状**：聊天面板显示"无法连接到Text2Cypher服务"
**解决**：
1. 检查Text2Cypher服务是否运行
2. 确认端口8003是否被占用
3. 检查防火墙设置

### 问题2：前端服务启动失败
**症状**：npm run dev 报错
**解决**：
1. 检查Node.js版本（建议16+）
2. 删除node_modules重新安装
3. 检查端口5173是否被占用

### 问题3：图标显示异常
**症状**：聊天按钮图标不显示
**解决**：
1. 检查@element-plus/icons-vue是否正确安装
2. 确认图标导入语句正确
