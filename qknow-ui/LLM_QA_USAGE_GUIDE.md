# LLM问答交互功能使用指南

## 📖 功能概述

LLM问答交互功能为知识图谱探索界面提供了智能的自然语言查询能力，用户可以通过中文描述查询需求，系统会自动生成相应的Cypher查询语句并返回结果。

## 🚀 快速开始

### 1. 启动服务

确保以下服务正在运行：

```bash
# 前端服务
cd qknow-ui
npm run dev
# 访问: http://localhost:5173

# Text2Cypher API服务
# 确保Text2Cypher服务运行在: http://localhost:8003
```

### 2. 访问图谱探索页面

1. 打开浏览器访问：`http://localhost:5173/app/graphExploration`
2. 点击顶部的"智能问答"按钮
3. 聊天面板会从右侧滑出

### 3. 开始对话

在聊天输入框中输入您的问题，例如：
- "查询所有人员信息"
- "查找技术专家"
- "分析实体关系"
- "显示掌握Java技术的人员"

## 💡 使用技巧

### 问题描述建议

**✅ 好的问题描述：**
- "查询所有人员的基本信息"
- "查找掌握Java技术的专家"
- "显示张三的工作经历"
- "分析实体之间的关系网络"

**❌ 避免的问题描述：**
- "查一下"（过于简单）
- "给我所有数据"（范围过大）
- "随便看看"（不明确）

### 查询类型示例

#### 1. 实体查询
```
问题：查询所有人员信息
预期：返回人员列表，包含姓名、职位等属性
```

#### 2. 关系查询
```
问题：查找掌握Java技术的人员
预期：返回掌握Java技术的人员列表
```

#### 3. 路径查询
```
问题：显示张三到李四的关系路径
预期：返回两个实体之间的连接路径
```

#### 4. 统计分析
```
问题：统计各技术领域的专家数量
预期：返回技术领域和对应的专家数量统计
```

## ⚙️ 配置设置

### 访问设置

1. 点击聊天面板右上角的设置按钮（⚙️）
2. 在设置对话框中可以配置：
   - **LLM模型**：选择使用的语言模型
   - **数据库**：选择目标数据库
   - **工作流类型**：选择查询处理流程
   - **超时时间**：设置查询超时时间（秒）

### 工作流类型说明

1. **text2cypher_with_1_retry_and_output_check**
   - 最完整的工作流
   - 支持重试机制和输出检查
   - 推荐用于生产环境

2. **naive_text2cypher**
   - 基础转换工作流
   - 执行速度快
   - 适合简单查询

3. **naive_text2cypher_with_1_retry**
   - 基础工作流 + 重试机制
   - 平衡性能和稳定性

## 🔧 功能特性

### 1. 智能对话
- 支持自然语言输入
- 自动生成Cypher查询
- 实时显示查询结果

### 2. 结果展示
- **Cypher查询**：显示生成的查询语句
- **执行结果**：以表格形式展示数据
- **执行时间**：显示查询耗时

### 3. 交互功能
- **代码复制**：一键复制Cypher查询
- **历史记录**：自动保存聊天历史
- **清空记录**：支持清空聊天记录

### 4. 持久化存储
- 聊天历史自动保存到本地存储
- 设置配置自动保存
- 页面刷新后保持状态

## 🛠️ 故障排除

### 常见问题

#### 1. 服务连接失败
**症状**：显示"无法连接到Text2Cypher服务"
**解决方案**：
- 检查Text2Cypher服务是否启动
- 确认API地址配置正确
- 检查网络连接

#### 2. 查询超时
**症状**：显示"查询超时"错误
**解决方案**：
- 简化问题描述
- 增加超时时间设置
- 检查数据库性能

#### 3. 结果为空
**症状**：查询成功但结果为空
**解决方案**：
- 检查数据库中是否有相关数据
- 尝试不同的查询描述
- 查看生成的Cypher查询是否正确

#### 4. 模型不可用
**症状**：显示"LLM模型不可用"
**解决方案**：
- 检查LLM服务配置
- 确认API密钥有效
- 联系管理员
